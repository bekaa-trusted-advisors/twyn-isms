## 1. Objetivo
Garantir a conformidade com direitos de propriedade intelectual (PI) no uso de software e conteúdos, e
proteger a PI proprietária do TWYN (algoritmo de vetorização biométrica, código-fonte).

## 2. Diretrizes
1. **Software licenciado:** uso apenas de software com licença válida; vedada a instalação não
   autorizada (ver `A.8.19` — POL-CMP-001).
2. **Componentes de terceiros / open-source:** inventário de dependências (SBOM) e verificação de
   compatibilidade de licenças no pipeline.
3. **PI proprietária:** o algoritmo e o código da API Face ID são **Confidenciais** (`POL-GOV-001`);
   acesso restrito (`A.8.4`) e protegido por NDA (`A.6.6`).
4. **Contribuições:** cláusulas de cessão de PI nos contratos de trabalho/prestação (`A.6.2`).
